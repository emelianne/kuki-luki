# Куки Луки — концепт сайта

Интерактивный 3D-концепт сайта для московской кофейни «Куки Луки».
Прокрутка: коробка открывается, шесть печенек по очереди выезжают крупным планом, падают в коробку, по клику — состав.

Это фан-концепт, не официальный сайт кафе. Автор концепта — Радмила Ефремова.

Технологии: Three.js (WebGL), 3D-модели печенек — Higgsfield (Tripo), коробка — Blender.
Промежуточная версия, работа продолжается.
